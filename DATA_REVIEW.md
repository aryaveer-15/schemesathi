# SchemeSathi data review

26 November 2026 · Pass 1

## Official link check

The live GET run covered 51 maintained schemes, 92 published references and 74 unique URLs. Fifty URLs returned a direct 2xx, one returned a redirect followed by a 200, two returned 404, two returned 403, four timed out and fifteen had transport or certificate errors. These are observations from this machine. A 2xx confirms an HTTP response. Scheme content and eligibility still require human review. Every scheme starts with a pending review date unless a date has been explicitly recorded after that review.

From the repository root, run this PowerShell command to regenerate the full local report at `LINK_REPORT.md`. Rerun from a regular network or open affected links in a browser when assessing restrictions, certificates and timeouts. The checker follows normal HTTPS redirects and records insecure or unsupported destinations without requesting them.

```powershell
npm.cmd --prefix server run check:links
```
